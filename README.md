# Insurance Operations Analytics — Excel

## Project Overview

This project analyzes insurance operations data using Microsoft Excel to understand policy transactions, premium performance, renewals, endorsements, SLA performance, quality, and employee productivity.

## Business Objective

The objective of this project is to analyze insurance operations performance and create a dashboard that helps understand:

- Policy transaction volume
- Premium performance
- Renewal performance
- Endorsement volume
- SLA achievement
- Quality performance
- Processing time
- Employee productivity

## Data Preparation & Cleaning

The dataset was prepared and cleaned in Excel before analysis.

Key data-cleaning activities included:

- Identifying and removing duplicate records
- Handling blank and missing values
- Standardizing categorical values
- Checking data consistency
- Preparing data for Pivot Table analysis

## Analysis & KPIs

The project includes analysis of:

- Total Policy Transactions
- Total Premium
- Total Endorsements
- Renewal Rate
- SLA Achievement %
- Quality Pass Rate
- Processing Time
- Employee-wise Policy Transactions
- Department-wise Performance
- Product Category-wise Premium

## Excel Techniques Used
